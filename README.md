Project: FinSight Finance Analysis
1. Business Problem
Financial institutions process large volumes of transactions, making it challenging to monitor financial performance, track transaction trends, analyze customer segments, and identify transaction risks. FinSight addresses this challenge by consolidating key financial metrics into a single interactive dashboard for efficient monitoring and data-driven decision-making.
2. Goal of the Dashboard
The goal is to provide a comprehensive view of financial performance by tracking transaction amounts, transaction volumes, average transaction value, fees, and taxes. Interactive filters for year, occupation, and category enable users to explore data and identify meaningful trends.
3. Walkthrough of Key Visuals
- KPI Cards: Display total amount, total transactions, average transaction value, total fees, and total tax, with previous-year comparisons.
- Monthly Trend Analysis: An area chart shows monthly transaction amounts to identify fluctuations and seasonal patterns.
- Gender Analysis: A doughnut chart compares transaction amounts by gender.
- Transaction Type Analysis: A table compares amounts, fees, taxes, and transaction counts across different transaction types.
- Customer Segmentation: A bar chart compares financial contributions from Retail, Premium, SME, Corporate, and Wealth customer segments.
- Transaction Status: A doughnut chart displays the distribution of successful, failed, and pending transactions.
- State-wise Analysis: A horizontal bar chart ranks states by total transaction amount, highlighting major contributing regions.
- Interactive Filters: Year, occupation, and category slicers allow users to customize the analysis.
4. Business Impacts & Insights
- Performance Monitoring: Provides a consolidated overview of financial KPIs and year-over-year changes.
- Customer Insights: Identifies customer segments and demographics contributing most to transaction value.
- Risk Management: Highlights failed and pending transactions for further investigation.
- Operational Efficiency: Helps compare transaction types to evaluate fee and tax contributions.
- Regional Strategy: Identifies high-performing states and opportunities for regional growth.
- Data-Driven Decisions: Enables management to identify trends, monitor performance, and prioritize improvement areas.
5. Tech Stack
- Power BI: Interactive dashboard development and data visualization.
- Power Query: Data cleaning, transformation, and preparation.
- DAX (Data Analysis Expressions): KPI calculations, time-based analysis, and year-over-year comparisons.
- Data Modeling: Relationships between transaction, customer, and geographic data.
- Excel / CSV: Potential source formats for importing and preparing financial data.
